# PIXEL TRADING FLOOR — 설치·계정 연결·사용 가이드 v1.7

AI 에이전트 13명이 분석·토론·리스크 심사·최종 승인을 거쳐 판정을 내리는 픽셀아트 트레이딩 오피스.

- 실행 환경 Windows · macOS · Node.js 22.18 이상 · Claude Code
- 이 문서는 화면 캡처 없이 글로만 설명한다. 화면 구성은 4장, 실제 화면은 `?demo=1`로 직접 볼 수 있다.

티커 하나를 입력하면 AI 에이전트들이 시장 데이터를 각자의 관점으로 분석하고, 강세·약세 논쟁을 벌인 뒤, 리스크 위원회의 심사와 포트폴리오 매니저의 승인을 거쳐 최종 판정을 냅니다 (알고리즘 모드 기준). 그 전 과정이 픽셀아트 사무실에서 말풍선과 터미널 로그로 중계됩니다. **분석 도구이며 이 앱에는 주문 기능이 없습니다.** 보유 중인 포지션을 입력하면 그 보유를 전제로 유지·추가·일부 청산·전량 청산을 판정하지만(6장), 실제 주문은 사용자가 거래소에서 직접 합니다.

## 1. 클로드가 반드시 필요합니다

이 앱의 에이전트는 분석할 때마다 클로드를 호출합니다. 실제 분석을 돌리려면 Claude Code가 설치되고 로그인돼 있어야 합니다. 기능별 필요 여부는 다음과 같습니다.

| 기능 | 클로드 | 설명 |
|---|---|---|
| 데모 모드 `?demo=1` | 불필요 | 녹화된 응답으로 에이전트·토론·판정·리포트 저장까지 연출이 재생됩니다. 외부 공급자에도 요청을 보내지 않습니다 |
| 전광판·시세 | 불필요 | 무료 공개 API만 씁니다. 시세 모니터로만 써도 됩니다 |
| 리포트 열람·다운로드 | 불필요 | `/reports` 페이지와 ZIP 다운로드 |
| ▶ ANALYZE 실전 분석 | 필수 | 에이전트가 실제로 사고하는 부분. 없으면 오류 코드(`E-*`)와 안내가 표시됩니다 |
| `/floor` 명령 | 필수 | 클로드 세션 안에서 도는 기능입니다 (8장) |

**요금은 어떻게 되나.** Claude Code는 Pro·Max·Team·Enterprise 구독 또는 Console(API) 계정이 필요합니다. 무료 플랜으로는 쓸 수 없습니다. 구독을 쓴다면 추가 결제 없이 구독 사용량만 소모합니다. 회당 호출 수는 알고리즘 11~13회(최대 17회), 스캘핑·강제 방향 5회(최대 7회)입니다. `/floor`는 세션 하나가 모든 역할을 맡아 호출이 하나로 합쳐집니다(8장).

## 2. 설치 — 3단계

Node.js 설치 → Claude Code 설치 → 계정 연결.

### 2-1. Node.js 설치 (필수)

nodejs.org에서 LTS를 받아 설치합니다. Windows는 Windows Installer(.msi), macOS는 macOS Installer(.pkg)를 받아 "다음"(계속)만 누르면 됩니다. macOS에서 Homebrew를 쓴다면 `brew install node@22`도 됩니다. 이 앱은 **Node.js 22.18 이상**이 필요합니다 (TypeScript를 빌드 없이 바로 실행합니다). 설치 후 확인:

```
node -v
```

`v22.18` 이상이 나오면 정상입니다. 설치 직후에는 터미널을 새로 열어야 합니다. 기존 창은 새로 설치된 프로그램을 인식하지 못해 `'node'은(는) 내부 또는 외부 명령이 아닙니다`(Windows) 또는 `command not found: node`(macOS) 오류가 납니다.

### 2-2. Claude Code 설치

세 가지 중 하나만 하면 됩니다. 공식 문서가 권장하는 것은 첫 번째입니다.

| 방법 | Windows | macOS (터미널 앱) |
|---|---|---|
| 네이티브 (권장, 자동 업데이트) | PowerShell에서 `irm https://claude.ai/install.ps1 \| iex` | `curl -fsSL https://claude.ai/install.sh \| bash` |
| 패키지 관리자 | `winget install Anthropic.ClaudeCode` (업데이트는 수동: `winget upgrade`) | `brew install --cask claude-code` (업데이트는 수동: `brew upgrade`) |
| npm | `npm install -g @anthropic-ai/claude-code` | 같음 |

Windows에서는 프롬프트에 `PS C:\…`처럼 PS가 붙어 있으면 PowerShell, `C:\…`만 있으면 CMD입니다. `irm … | iex`는 PowerShell 전용이고, CMD에서는 `curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd`를 씁니다.

설치 확인: `claude --version`, `claude doctor`(설치·설정 진단).

### 2-3. 클로드 계정 연결 (로그인)

터미널에서 `claude`를 실행하면 첫 실행 시 브라우저가 열리며 로그인 화면이 나타납니다. 완료되면 `Login successful`이 표시됩니다.

| 상황 | 해결 |
|---|---|
| 브라우저가 안 열린다 | 터미널에서 `c`를 누르면 로그인 주소가 복사됩니다. 브라우저에 붙여넣으세요 |
| 브라우저에 코드가 표시됨 | 그 코드를 터미널의 `Paste code here if prompted` 자리에 붙여넣습니다 |
| 계정을 바꾸고 싶다 | 세션 안에서 `/logout` 후 다시 `claude` 실행 |
| 지금 어떤 계정인지 확인 | 세션 안에서 `/status` |
| 로그인 만료 경고 | `/login`으로 갱신 |

**⚠ 실수로 API 과금이 되는 경우.** 환경변수 `ANTHROPIC_API_KEY`가 설정돼 있으면 클로드는 구독 대신 그 API 키로 청구합니다. 이 앱처럼 비대화형(`claude -p`)으로 호출할 때도 키가 있으면 항상 그 키가 쓰입니다. 구독으로만 쓰려면 지우세요.

```
:: 확인 (PowerShell)
echo $env:ANTHROPIC_API_KEY

:: 현재 창에서만 해제
$env:ANTHROPIC_API_KEY = $null

:: 영구 해제
[Environment]::SetEnvironmentVariable("ANTHROPIC_API_KEY", $null, "User")
```

macOS(터미널 앱)에서는 이렇게 합니다.

```
# 확인
echo $ANTHROPIC_API_KEY

# 현재 창에서만 해제
unset ANTHROPIC_API_KEY

# 영구 해제: ~/.zshrc 또는 ~/.zprofile에서 export ANTHROPIC_API_KEY=… 줄을 지우고 터미널을 새로 연다
grep -n ANTHROPIC_API_KEY ~/.zshrc ~/.zprofile
```

세션 안에서 `/status`를 실행해 API key 행이 없고 구독 계정이 표시되는지 확인하면 확실합니다.

### 2-4. 앱 실행

압축은 아무 폴더에나 풉니다(경로에 한글·공백이 있어도 됩니다). 패키지 설치는 필요 없습니다. 외부 라이브러리를 하나도 쓰지 않습니다.

| 방법 | 실행 |
|---|---|
| 더블클릭 (가장 쉬움) · Windows | `start-floor.cmd` — 서버를 켜고 브라우저를 자동으로 엽니다 |
| 더블클릭 (가장 쉬움) · macOS | `start-floor.command` — Finder에서 더블클릭하면 터미널 창이 열리고 서버를 켠 뒤 브라우저를 엽니다 |
| 터미널 | `npm start` |
| 터미널 (직접) | `node src/server/main.ts --open --doctor` |

서버 창(Windows의 검은 창, macOS의 터미널 창)이 서버 본체이므로 닫으면 앱이 꺼집니다.

**시작 점검.** 시작 파일은 서버를 켜기 전에 Node.js 버전, Claude Code 설치, 로그인 여부를 확인해 서버 창 맨 위에 요약합니다.

```
시작 점검 (Node.js·Claude)
  [정상] Node.js 버전: 22.23.2
  [정상] Claude CLI: 실행 파일 직접 실행
  [정상] Claude CLI 버전: 2.1.285
  [오류] 인증 방식: 로그인되어 있지 않음
         → 터미널에서 claude를 실행해 로그인하세요
  ⚠ 분석을 실행하려면 위 [오류] 항목을 먼저 해결하고 이 창을 닫았다가 다시 여세요. 데모와 지난 리포트 보기는 지금도 쓸 수 있습니다.
```

`[오류]`가 있어도 서버는 켜집니다. 데모(`?demo=1`)와 지난 리포트는 클로드 없이도 볼 수 있기 때문입니다. `→` 줄의 안내대로 고친 뒤 서버 창을 닫았다가 다시 여세요. `[주의]`는 분석을 막지 않습니다(예: Node.js 보안 업데이트 권장). Node.js가 없거나 22.18보다 오래되었으면 서버를 켜지 않고 설치 안내만 표시합니다. 더 자세한 진단은 `/diagnostics`(10장)에서 봅니다.

**macOS 처음 실행.**
- 압축 파일로 받았다면 처음 더블클릭할 때 "확인되지 않은 개발자" 또는 "열 수 없음" 경고가 뜰 수 있습니다. `start-floor.command`를 Control 키를 누른 채 클릭(또는 오른쪽 클릭) → **열기** → **열기**를 누르면 다음부터는 바로 열립니다. 이 메뉴가 없으면 **시스템 설정 → 개인정보 보호 및 보안** 아래의 **그래도 열기**를 누릅니다.
- "권한이 없어 열 수 없습니다"가 뜨면 실행 권한이 빠진 것입니다. 터미널에서 앱 폴더로 이동해 `chmod +x start-floor.command start-floor-lan.command`를 한 번 실행하세요.
- 시작 파일은 Homebrew(`node@22` 포함)·Volta·nvm으로 설치한 Node.js도 찾아봅니다.

**접속 주소.** 서버는 시작할 때마다 새 접근 토큰을 만들고, **토큰이 붙은 주소(`http://localhost:8000/?t=…`)로 브라우저를 직접 엽니다.** 이 PC에서도 토큰 없이 `localhost:8000`을 처음 입력하면 접속이 거부됩니다(같은 PC의 다른 프로그램이 앱을 조작하지 못하게 하려는 장치). 한 번 열린 브라우저는 서버를 끌 때까지 `localhost:8000`으로 다시 열 수 있고, 서버를 다시 켜면 새 주소로 다시 열립니다. 서버 창에도 같은 주소가 표시됩니다. 주소를 파일로 남기지 않으니 필요하면 서버 창에서 복사하세요.

| 주소 | 용도 |
|---|---|
| `localhost:8000` | 실전 모드 — 실제 AI 분석 (클로드 필요) |
| `localhost:8000/?demo=1` | 데모 모드 — 클로드 없이 전체 연출 재생 |
| `localhost:8000/reports` | 분석 결과 목록·열람·다운로드 |

(모두 서버가 열어 준 브라우저에서. 8000번 포트가 이미 쓰이는 중이면 먼저 켜져 있던 서버 창을 닫는 것이 가장 깔끔합니다. 포트를 바꾸려면 CMD에서 `set PORT=8123 && npm start`, PowerShell에서 `$env:PORT=8123; npm start`, macOS 터미널에서 `PORT=8123 npm start`.)

```
시장 데이터  Binance · Yahoo · CoinGecko · 뉴스 RSS · 공포탐욕지수 · 환율 · 거래소별 무기한 선물
        │  (작업당 한 번 수집해 고정한 스냅샷. 에이전트는 외부를 직접 조회하지 못한다)
        ▼
① 애널리스트 팀 (병렬 4명)   TARO 기술적 · DIANA 기본적 · NOVA 뉴스 · VIBE 센티먼트
        ▼
② 리서치 토론 (최대 2라운드)  BULL 강세 논거 ⇄ BEAR 약세 논거 — 서로의 주장을 직접 반박

        ▼
```

| 에이전트 | 역할 | 무엇을 보는가 |

| VIBE | 센티먼트 | 공포·탐욕 지수, 헤드라인 전반의 심리 |
| BULL | 강세 논거 | 애널리스트 리포트에서 상승 근거를 뽑아 주장 |

| BLITZ | 스캘퍼 | 15분봉 단타 — 진입 트리거·목표·무효화 레벨 |
| GUARD | 리스크 관리 | 20배 청산 여유 검증, 권장 비중, 진입 금지 조건 |
| RISKY | 공격적 리스크 | 기회비용 관점 — 계획이 과도하게 방어적인지 |
| SAFE | 보수적 리스크 | 최악 시나리오·꼬리위험 — 비중 축소·손절 상향 요구 |
| NEUTRAL | 중립적 리스크 | 양측 주장을 가르고 조건부 승인안 제시 |
| ACE | 수석 트레이더 | 전부 종합해 판정 (확신도·진입·손절·목표) |
| PM | 포트폴리오 매니저 | ACE 계획을 승인·수정·기각하는 최종 관문 (알고리즘 모드만) |

**모델이 내는 것은 제안일 뿐입니다.** 각 에이전트의 출력은 형식 검사를 거치고, 손절 방향·위험 거리 같은 규칙은 모델이 아니라 코드가 적용합니다. 규칙을 통과하지 못한 판정은 `거래 없음`으로 낮춰지거나 막히며, 그 이유가 화면에 표시됩니다. 필수 시세를 받지 못하면 모델을 부르지 않고 `데이터 부족`으로 끝납니다. 추정 시세는 판정 기준으로 쓰지 않습니다.

**논문 구조를 어디까지 구현했나.** 이 앱은 TradingAgents 논문(멀티 에이전트 금융 의사결정)의 구조를 따릅니다. 애널리스트 분업 → 강약 토론 → 트레이더 판정 → 리스크 위원회 심사 → PM 승인까지 재구현했습니다. 과거 판정 회고(같은 종목의 지난 판정과 이후 가격 흐름을 다시 읽는 기능)는 구현돼 있지만 **기본으로 꺼져 있습니다**. 논문 저자의 원본 코드를 쓴 것이 아니라 같은 구조를 다시 만든 것입니다.

## 4. 화면 읽는 법

### 4-1. 전광판 — 가격과 8비트 차트

큰 LED 가격과 등락률, MARKET OPEN 배지(장 시간 자동 판별), 종가 라인 위의 MA20(금색)·MA50(파랑) 오버레이, 최근 20봉 고·저 점선 레벨, 하단 날짜 라벨. **전광판은 모든 종목에서 보입니다.** 15초마다 갱신됩니다. 등락률은 직전 완성 봉의 종가 기준이며, 주식은 장 마감 뒤 1시간 안이면 전 거래일 종가 기준입니다.

### 4-2. 사무실 — 방 4개

- **방 꾸밈.** 방마다 벽에 모니터·책장·시계·경고등·표지판 같은 소품이 있습니다 (장식이며 판정과 무관합니다). 쉬는 자리가 아닌 자리에는 분석 전에도 말풍선이 떠 있고, 말이 없으면 `분석 대기 중…`, 호출 중이면 `생각 중…`이 보입니다.
- **애널리스트 팀.** 각자 말풍선으로 결론을 먼저 말합니다. 말풍선을 클릭하면 그 에이전트의 브리핑 전문이 열립니다. 흐릿한 캐릭터는 이번 모드에서 쉬는 자리입니다.
- **리서치룸.** BULL과 BEAR가 토론합니다.
- **리스크 위원회** (알고리즘 모드). RISKY·SAFE·NEUTRAL이 ACE의 1차 계획을 놓고 논쟁합니다. 스캘핑·강제 방향 모드에서는 같은 방이 스캘핑 데스크(BLITZ·GUARD)로 바뀝니다.
- **트레이딩 본부.** ACE와 PM이 앉아 있고 오른쪽이 판정 패널입니다. 액션·확신도·진입/손절/목표·근거, PM 수정승인 배지와 권장 비중이 표시됩니다. **스캘핑·강제 방향 모드에는 PM 자리가 없고 최종 결정자는 ACE입니다.** 그래서 이 모드의 결과에는 `PM 승인` 표시가 나오지 않습니다.

판정 패널의 표시 방식:

- **액션**은 `롱 진입` / `숏 진입` / `거래 없음`입니다. **전망**(`강세` / `약세` / `중립`)은 액션과 별도로 표시됩니다. "거래는 안 하지만 강세 전망"이 가능합니다.
- **확신도**는 `LOW` / `MEDIUM` / `HIGH` 세 단계만 표시합니다. 퍼센트로 보이지 않으며, **적중 확률이 아닙니다.** 판정 규칙에도 쓰이지 않습니다.
- 규칙이 판정을 바꿨다면 (예: 위험 거리 초과로 `거래 없음`) 그 사유 코드와 설명이 함께 나옵니다.

### 4-3. 에이전트 콘솔 — 긴 브리핑이 흐르는 곳

우측 콘솔에 데이터 수집 로그 → 뉴스 헤드라인 → (켜져 있다면) 과거 판정 회고 → 에이전트별 브리핑 전문 → 최종 판정이 순서대로 타이핑되며 흐릅니다. 상단 탭으로 전체 / 에이전트 / 토론만 골라 볼 수 있습니다. 말풍선은 결론 요약이고, 실제 근거는 콘솔의 브리핑 전문에 있습니다. 각 브리핑은 관찰한 수치 인용 → 해석 → 반대 시나리오 → 판단이 바뀌는 트리거 순서로 구성됩니다.

에이전트가 인용한 근거를 시스템이 다시 대조해, 확인할 수 없는 참조는 주장 옆에 `⚠ 근거 확인 불가`, 인용한 수치가 원본과 다르면 `⚠ 수치 불일치`로 표시합니다(콘솔과 리포트 모두). 이 표시는 경고일 뿐 판정을 바꾸지 않으니, 표시가 붙은 주장은 원본 수치를 직접 확인하고 읽으세요.

### 4-3-1. 하단 티커 — 주요 종목 등락

### 6-3. 보유가 있을 때의 판정

분석할 종목을 들고 있으면 판정은 신규 진입이 아니라 **내 포지션에 할 일** 네 가지 중 하나가 됩니다.

| 판정 | 화면 표기 | 뜻 |
|---|---|---|
| HOLD | 유지 | 그대로 둔다 (손절·목표 조정 제안이 붙을 수 있음) |
| ADD | 추가 진입 검토 | 같은 방향으로 더 산다. 신규 진입과 같은 근거 기준을 만족할 때만 |
| REDUCE | 일부 청산 검토 (25·50·75%) | 일부를 정리한다 |
| EXIT | 전량 청산 검토 | 모두 정리한다 |

- 방향이 뒤집혔다고 보더라도 한 번에 반대 포지션으로 갈아타는 판정은 내지 않습니다. 먼저 `EXIT`가 나오고, 청산한 뒤 다시 분석하면 보유 없음 상태로 진입 여부를 봅니다.
- 시장 전망(강세 / 약세 / 중립)은 판정과 따로 표시됩니다. 예: 롱 보유 · 약세 전망 · 전량 청산 검토.
- 판정 패널에는 판정에 쓴 포지션이 `사용한 포지션:` 한 줄로 표시됩니다(시장·방향·레버리지·평단·수익률·손절·청산가·기준 시각). **입력한 값이 맞는지 이 줄에서 먼저 확인하세요.**
- 애널리스트 4명과 강세·약세 토론은 포지션을 보지 못합니다. 보유 여부가 시장 분석을 한쪽으로 끌고 가지 않게 하려는 장치입니다. 포지션은 판정을 내리는 역할(스캘핑의 BLITZ·GUARD·ACE, 알고리즘의 ACE·리스크 위원 3명·PM)만 봅니다. 그래서 AI 호출 수는 5장과 같습니다.
- 평단과 현재 손익은 판정의 근거로 쓰지 않도록 지시되어 있습니다(본전 생각에 버티는 편향 방지). 손절을 넓히는 제안은 규칙이 막습니다.

### 6-4. 수량 제안의 의미와 한계

신규 진입과 추가 진입(ADD) 판정에는 **제안 수량**이 붙을 수 있습니다. AI가 정하는 값이 아니라 앱의 코드가 다음과 같이 계산합니다.

- 한 번에 잃어도 되는 금액 = 해당 통화 총 자산 × 1회 손실 한도 %
- 제안 수량 = 그 금액 ÷ |진입 기준가 − 손절가|. 추가 진입은 기존 포지션이 손절까지 갈 때의 손실을 먼저 빼고 남은 한도로 계산합니다.

한계:
- **수수료·슬리피지·펀딩비를 넣지 않은 참고값입니다.** 화면에도 `총 자산 대비 손실 한도 N% 기준 · 수수료·슬리피지·펀딩비 미반영 · 참고용`이 함께 표시됩니다.
- 손절에 정확히 체결된다고 가정합니다. 급변동·갭에서는 손실이 더 커질 수 있습니다.
- 기존 포지션에 손절이 없으면 추가 진입 수량을 계산하지 않습니다(`보유 포지션에 손절이 없어 추가 진입 수량을 계산하지 않음`).
- 무기한에서 필요 증거금이 총 자산의 50%를 넘으면 경고가 붙습니다.
- 일부 청산은 비율(25·50·75%)로만 표시합니다.

### 6-5. 포지션 정보는 어디에 저장되고 어디로 가나

- 저장: 이 PC의 앱 폴더 `.floor/positions.json` 한 곳입니다(나만 읽고 쓸 수 있는 권한, 직전 버전은 `.floor/positions.json.bak`). 다른 사람과 공유되지 않고, 각자 자기 PC에 자기 포지션을 저장합니다.
- **AI(클로드)에게 보내는 것은 비율 정보뿐입니다**: 방향, 레버리지, 마진 방식, 평단가, 현재 손절·목표 가격, 수익률·손절까지 거리·청산가까지 거리 같은 비율, 보유 시간. **금액·수량·총 자산·메모는 보내지 않습니다.** 이 비율 정보도 실전 분석 때 Claude Code를 통해 Anthropic으로 전송된다는 점은 알고 쓰세요(11장 "데이터가 오가는 곳").
- 시세·뉴스를 조회하는 외부 공급자에게는 포지션 정보를 보내지 않습니다.
- 분석 기록(`jobs/`)과 리포트 JSON(`reports/*.json`)에는 재현을 위해 판정에 쓴 포지션이 그대로 남습니다. 리포트 Markdown에는 비율 정보와 제안 수량만 들어가고 총 자산은 들어가지 않습니다.
- 진단 화면에는 `포지션 N건 저장됨`만 표시됩니다.

## 7. 결과물 — 저장과 다운로드

|---|---|
| `/reports` | 목록 — 분석 / 시뮬레이션 / 간이 / 데모 탭으로 나뉘며 클릭하면 열람 |

## 8. 사용량을 아끼는 방법 — /floor

브라우저 없이 클로드 세션에서 바로 분석할 수도 있습니다. `/floor`는 **현재 세션 하나가 여러 역할의 발언을 맡는** 방식이라 에이전트마다 별도 호출을 하지 않아 사용량이 적게 듭니다.

```
:: 프로젝트 폴더에서 클로드 열기
cd 압축푼폴더
claude
```

```
/floor 하이닉스 scalp
/floor BTC algorithm
/floor 삼성전자 강제
```

모드는 `algorithm` · `scalp` · `forced_direction` 또는 별칭 `알고리즘` · `스캘핑` · `강제`입니다.

**브라우저 분석과 같은 점**
- 데이터 수집·스냅샷 고정·형식 검사·규칙 적용·리포트 저장은 브라우저와 같은 **공통 코어**가 합니다. 손절 규칙·위험 거리 검사 같은 판정 검증이 똑같이 적용됩니다.
- 결과는 `reports/`에 저장되고 `/reports`에서 `분석` 또는 `시뮬레이션` 탭으로 볼 수 있습니다.

**다른 점 (알아 둘 것)**
- **`단일 세션 분석` 배지가 붙습니다.** 모든 역할을 한 세션이 이어서 말하므로 역할들의 독립성이 완전하지 않습니다(예: 애널리스트 4명이 서로의 결론을 보지 않은 척 써야 합니다). 리포트에도 `shared_context`로 기록됩니다. 독립적으로 분석한 결과가 필요하면 브라우저의 ▶ ANALYZE를 쓰세요.
- `/floor`는 `간이 분석`이 아닙니다. 데이터 고정과 판정 검증이 적용되는 정식 분석이며, 독립성만 다릅니다.
- `/floor`는 **도구가 3개로 제한된 전용 하위 에이전트**에서 실행됩니다. Bash·Read·Write만 쓰고, Bash는 공통 코어의 `snapshot`·`next`·`submit`·`finalize` 명령만, Read는 그 작업의 입력·프롬프트·스키마 파일만, Write는 그 작업의 출력 파일만 허용됩니다. 웹 조회·검색·다른 파일 접근은 막혀 있어, 뉴스에 섞인 "이걸 사라" 같은 문장이 도구를 조작할 수 없습니다.
- 모델은 세션에서 `/model`로 바꿀 수 있습니다. 자주 돌린다면 가벼운 모델이 절약에 유리합니다.
- 실측 예 (sonnet, BTC scalp): 약 78초, 보고 비용 약 $0.39.

## 9. 다른 PC나 휴대폰에서 보기

기본 실행은 이 PC에서만 접속됩니다. 같은 네트워크의 다른 기기에서 **보기만** 하려면 다음 순서를 따릅니다.

1. 집·사무실의 **신뢰할 수 있는 Wi-Fi**인지 확인합니다. 공용·게스트 Wi-Fi에서는 쓰지 마세요.
2. Windows는 `start-floor-lan.cmd`, macOS는 `start-floor-lan.command`로 실행합니다. (기본 `start-floor.cmd`·`start-floor.command`로는 다른 기기가 접속할 수 없습니다)
3. 서버 창에 표시된 **접속 주소(토큰 포함)** 를 다른 기기 브라우저에서 엽니다. 주소는 **2시간 뒤 만료**됩니다.
4. 다른 기기에서는 화면과 리포트를 **보기만** 할 수 있습니다. 분석 실행, 전체 ZIP, 진단, 보유 포지션 입력은 서버 PC에서만 됩니다. 다른 기기에 보이는 화면·리포트에서는 수량·총 자산이 `[masked]`로 가려집니다.
5. Windows 방화벽이 물어보면 **개인 네트워크**에만 허용합니다. macOS에서 "들어오는 네트워크 연결을 허용하겠습니까?"라고 물으면 **허용**합니다(집·사무실 네트워크에서만).

주의: LAN 통신은 **암호화되지 않은 HTTP**입니다. 같은 네트워크의 다른 사람이 주소(토큰)를 보면 화면과 리포트를 볼 수 있으므로 신뢰하는 네트워크에서만 쓰고, 다 봤으면 서버 창을 닫으세요. 접속이 안 되면 두 기기가 서로 다른 네트워크에 있는 경우가 대부분입니다(한쪽이 테더링·게스트 와이파이).

## 11. 반드시 알고 쓰셔야 할 것

**투자 조언이 아닙니다.** 이 프로그램은 AI 분석 도구입니다. 에이전트의 분석·토론·판정은 참고용 콘텐츠일 뿐이며, 판정을 그대로 따라 매매하지 마십시오. 투자의 최종 판단과 책임은 전적으로 사용자 본인에게 있습니다.

**20배 레버리지의 의미.** 격리 20배에서는 대략 5% 안팎으로 역행하면 증거금이 소진될 수 있습니다. 이 앱이 표시하는 위험 거리는 **단순 근사치이며 실제 청산가는 거래소·수수료·유지증거금에 따라 다릅니다.** 앱은 사용자의 거래소·마진 방식을 모르므로 청산가를 계산하지 않습니다. 15분봉 변동성이 그 절반을 넘는 종목이라면 한 번의 스파이크에 손절과 청산이 동시에 걸릴 수 있습니다. GUARD·SAFE가 반복하는 지정가 강제 손절과 풀 사이징 금지는 빈말이 아닙니다.

**탭비트 가격은 추정치입니다.** 탭비트는 API 직접 조회가 막혀 있어 동일 기초자산을 다루는 거래소들의 평균으로 추정해 표시합니다. 실제 체결가와 차이가 있을 수 있으며, **추정 시세는 판정 기준으로 쓰이지 않습니다.** 주문 전에는 반드시 거래소 화면을 직접 확인하십시오.

**이 프로그램이 하지 않는 것**
- 실제 주문·거래·자금 이동을 하지 않습니다. 분석과 기록까지만 수행합니다. 보유 포지션을 입력해도 거래소에 연결하지 않으며, 유지·청산 판정과 제안 수량은 참고용입니다. 주문은 사용자가 거래소에서 직접 합니다.
- 거래소 API 키나 결제 수단을 일절 요구하거나 사용하지 않습니다.
- 자동매매 기능이 없습니다. 넣지 마십시오.

**데이터가 오가는 곳**
- 이 앱은 시세·뉴스·지표를 보여주고 분석하기 위해 외부 시장 데이터 공급자(Binance, Yahoo Finance, CoinGecko, 뉴스 RSS, 공포탐욕지수, 환율, 거래소별 선물 시세)에 조회 요청을 보냅니다. 이때 조회하는 종목 정보가 해당 공급자에게 전달됩니다.

- 분석 리포트는 사용자 PC의 `reports/` 폴더에 저장됩니다. 앱은 별도의 운영자 서버로 리포트를 업로드하지 않습니다.

- 이 앱은 거래소 API 키, 결제 정보, 계정 비밀번호를 요청하거나 전송하지 않습니다.

**뉴스 같은 외부 글은 믿지 않는 데이터로 다룹니다.** 헤드라인 안에 "이걸 매수하라" 같은 문장이 있어도 에이전트는 명령이 아니라 분석 대상으로만 읽습니다.
